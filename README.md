# 🎭 Mafia LAN Pro

لعبة مافيا جماعية بالوقت الفعلي (FastAPI + WebSockets) بواجهة عربية RTL مظلمة تعمل على الهواتف.

## الأدوار
مافيا 🦹‍♂️ · طبيب 👨‍⚕️ · محقق 🕵️ · مدني بريء 🧑‍🌾

## كيف تُلعب
1. أحد اللاعبين (الهوست) يضغط **إنشاء غرفة** فيظهر كود من 4 أرقام.
2. بقية اللاعبين يكتبون الكود ويضغطون **دخول** (4 لاعبين على الأقل).
3. الهوست يبدأ اللعبة؛ كل لاعب يكشف دوره سراً لمدة 5 ثوانٍ فقط.
4. ليلاً: المافيا تقتل، الطبيب يحمي، المحقق يحقق، والمدنيون ينقرون للتمويه.
5. نهاراً: نقاش ثم تصويت (مع خيار الامتناع 🏳️) وإقصاء.
6. زر **تجربة سريعة مع البوتات** يبدأ لعبة كاملة بضغطة واحدة.

> الهوست هو من يدير منطق اللعبة؛ إذا خرج يتوقف التقدم حتى يعود (يعود تلقائياً عند إعادة فتح الصفحة).
> السيرفر يخفي أدوار الآخرين عن متصفحات اللاعبين.

## التشغيل محلياً
```bash
pip install -r requirements.txt
uvicorn server:app --host 0.0.0.0 --port 10000
```
ثم افتح `http://localhost:10000` (أو عنوان جهازك على الشبكة المحلية من الهواتف).

## النشر على Render
1. ارفع محتوى المشروع إلى مستودع GitHub (الملفات في الجذر).
2. في Render: **New +** ← **Web Service** ← اختر المستودع.
3. **Runtime / Language:** `Docker` (يكتشف الـ Dockerfile تلقائياً).
4. لا حاجة لأي Environment Variables؛ Render يمرر `PORT` والـ Dockerfile يستخدمه.
5. اضغط **Create Web Service** وانتظر البناء، ثم افتح الرابط وشاركه مع اللاعبين.

ملاحظات:
- مسار فحص الصحة: `/health`
- الخطة المجانية تُنيم الخدمة بعد خمول؛ الحالة محفوظة في الذاكرة فقط وتُفقد عند إعادة التشغيل.
- الاتصال يستخدم `wss://` تلقائياً عند فتح الموقع عبر HTTPS.

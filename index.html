      📖 دليل قوانين وأدوار لعبة المافيا

      🎯 فكرة اللعبة الأساسية:

      ينقسم اللاعبون سراً إلى فريقين: المافيا (يعرفون بعضهم ويسعون لاغتيال أهل المدينة ليلاً) والمدنيون (الأغلبية الذين يحاولون كشف المافيا والتصويت لطردهم نهاراً).

      🦹‍♂️ المافيا (Mafia)

      يستيقظون في الليل عبر شاشات هواتفهم لاختيار ضحية واحدة لاغتيالها بصمت، وفي النهار يتظاهرون بأنهم أبرياء.

      👨‍⚕️ الطبيب (Doctor)

      يختار كل ليلة لاعباً واحداً (أو نفسه) لحمايته. إذا استهدفت المافيا نفس الشخص، ينجو من الاغتيال!

      🕵️ المحقق (Detective)

      يختار كل ليلة لاعباً واحداً ليفحص هويته السرية، ويخبره النظام فوراً هل هو من المافيا أم بريء.

      🧑‍🌾 المدني البريء (Civilian)

      ليس لديه مهمة ليلية (يمتلك أزرار تمويه على هاتفه حتى لا ينكشف)، وسلاحه الأقوى هو النقاش والتصويت نهاراً.

      🏆 متى تنتهي اللعبة؟

      • يفوز المدنيون: عند إقصاء جميع أفراد المافيا بالكامل.
      • تفوز المافيا: عندما يتساوى عدد الأحياء من المافيا مع عدد الأحياء من المدنيين (لأنهم يسيطرون على التصويت).

      💻 كود سيرفر الشبكة المحلية (FastAPI + WebSockets)

      لتشغيل اللعبة عبر نقطة الاتصال (Hotspot) أو الراوتر المحلي بين الهواتف

      🚀 خطوات التشغيل في 30 ثانية على حاسوبك (Linux / Windows / Mac):

      1. احفظ ملف الواجهة الحالي باسم index.html وبجانبه ملف السيرفر أدناه باسم server.py.
      2. ثبّت المكتبات: pip install fastapi "uvicorn[standard]"
      3. شغّل السيرفر على الشبكة المحلية: uvicorn server:app --host 0.0.0.0 --port 8000
      4. يدخل أصدقاؤك المتصلون بنفس الـ Wi-Fi أو الـ Hotspot على عنوان جهازك http://192.168.X.X:8000.
      ملف server.py الكامل: 
      from fastapi import FastAPI, WebSocket, WebSocketDisconnect
from fastapi.responses import FileResponse
from typing import Dict, List
import json

app = FastAPI(title="Mafia LAN Pro Server")
rooms_ws: Dict[str, List[WebSocket]] = {}
rooms_state: Dict[str, dict] = {}

@app.get("/")
async def serve_ui():
    return FileResponse("index.html")

@app.websocket("/ws/{room_code}")
async def room_socket(ws: WebSocket, room_code: str):
    await ws.accept()
    rooms_ws.setdefault(room_code, []).append(ws)
    # إرسال آخر حالة محفوظة للغرفة فور انضمام لاعب جديد
    if room_code in rooms_state:
        await ws.send_text(json.dumps(rooms_state[room_code]))
    try:
        while True:
            raw = await ws.receive_text()
            msg = json.loads(raw)
            if msg.get("type") == "SYNC_STATE":
                rooms_state[room_code] = msg
            # بث التحديث لجميع هواتف الغرفة على الشبكة المحلية
            for client in list(rooms_ws.get(room_code, [])):
                try:
                    await client.send_text(raw)
                except:
                    rooms_ws[room_code].remove(client)
    except WebSocketDisconnect:
        if ws in rooms_ws.get(room_code, []):
            rooms_ws[room_code].remove(ws)
      💡 يتصل التطبيق تلقائياً بالـ WebSocket عند تشغيله عبر server.py!
